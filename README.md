# Task-Tracker CLI

Java CLI-Anwendung zur Verwaltung von Aufgaben.

## Team
- [Milana] (Product Owner)
- [Dilara] (Scrum Master)
- [Fromm, Öszoy] (Developer)

## Beschreibung
Der Task-Tracker ermöglicht das Erstellen, Anzeigen, Bearbeiten, Filtern und Löschen von Aufgaben. 
Er hilft dabei, To-Dos übersichtlich zu verwalten.

## Technologien
- Java 21
- Git / GitHub

## Getting Started
```
javac src/TaskTracker.java
java -cp src TaskTracker
```

## Projektstruktur
- src/: enthält den Java-Code
- docs/: enthält Dokumentation wie User Stories und Rollen
- abgaben/: enthält Abgaben der Wochen
