## US-001: Task anlegen
**Als** Benutzer **möchte ich** eine neue Aufgabe mit Titel und Beschreibung erstellen, **damit** ich meine To-Dos festhalten kann.

### Akzeptanzkriterien
- [ ] Titel ist Pflichtfeld
- [ ] Aufgabe wird gespeichert
- [ ] Status ist standardmäßig „offen“

---

## US-002: Tasks anzeigen
**Als** Benutzer **möchte ich** alle meine Aufgaben in einer Liste sehen, **damit** ich einen Überblick über meine To-Dos habe.

### Akzeptanzkriterien
- [ ] Tasks werden angezeigt
- [ ] Titel und Status sind sichtbar
- [ ] Liste aktualisiert sich nach Änderungen

---

## US-003: Task bearbeiten
**Als** Benutzer **möchte ich** bestehende Aufgaben bearbeiten können, **damit** ich Änderungen vornehmen kann.

### Akzeptanzkriterien
- [ ] Titel und Beschreibung können geändert werden
- [ ] Änderungen werden gespeichert
- [ ] Aktualisierte Daten werden angezeigt

---

## US-004: Task löschen
**Als** Benutzer **möchte ich** Aufgaben löschen können, **damit** ich erledigte oder unnötige Aufgaben entfernen kann.

### Akzeptanzkriterien
- [ ] Task kann ausgewählt werden
- [ ] Task wird dauerhaft gelöscht
- [ ] Liste aktualisiert sich danach

---

## US-005: Task filtern
**Als** Benutzer **möchte ich** Aufgaben nach Status filtern, **damit** ich mich auf bestimmte Tasks konzentrieren kann.

### Akzeptanzkriterien
- [ ] Filtern nach Status (offen/erledigt)
- [ ] Nur passende Tasks werden angezeigt
- [ ] Filter kann zurückgesetzt werden
